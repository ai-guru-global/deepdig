01 /

定位声明

Positioning Statement

对于需要可信实时信息的 AI IDE 用户与 Agent 开发者，
DeepDig 是多源交叉检索与事实核查的 MCP 服务器——
它不像搜索 API 返回“结果列表”，而是仲裁“哪些信息彼此印证、哪些存在冲突”。

支柱 A · 抗幻觉

多引擎交叉验证 + ✦ 信源标记，单点幻觉与死链在仲裁层被拦截，结论自带溯源脚注。

支柱 B · 中文原生

Qwen/GLM/Kimi 三家中文生态底座，覆盖国内新闻、技术与学术信源，无需出境网络。

支柱 C · 零锁定

MIT 开源 + BYOK：Key 在用户手里，无中间商加价、无遥测；entry-point 插件可接任意检索源。

02 /

市场时机 · Why Now

WINDOW-1

Agent 检索成为高频原语

2026 年 MCP 已是 IDE 与 Agent 的标配协议，联网检索是其中调用频次最高的工具之一； 主流 MCP 目录（Smithery / PulseMCP / glama / mcp.so / 魔搭）流量快速集中，分发窗口正开着。

WINDOW-2

信任赤字倒逼可溯源

单源检索的幻觉、死链与过时信息已成为 Agent 落地的头号投诉；行业选型共识已把 “信源标注 + 交叉验证”列为硬指标——这正是 DeepDig 的产品内核。

WINDOW-3

中文供给断层

海外检索 API 中文表现一般且需出境；国内官方 MCP 均为单引擎锁定。多源仲裁 + 中文原生 + 开源自托管的组合位，目前无人占住。

横轴：单源 → 多源仲裁；纵轴：工具/基建层 → 认知/综合层。右上象限是空位。

官方单引擎 MCP单引擎包装❌✅按量（29 元/千次档）最大竞压来源：若升级多源，我方靠中立聚合+自托管守住
SearXNG / wigolo免费 SERP 聚合⚠️ 多源无仲裁一般免费价格敏感用户分流；我方卖可信度不卖低价

Open Core 三层

层内容定价
L1 开源本地 BYOK / 自托管 Gateway 全功能MIT · 永久免费
L2 托管团队共享 Key 池、用量分析、审计日志按席订阅（内测后）
L3 企业私有化、合规审计、SLA、专属插件源年度授权

红线：不赚检索差价。卖托管与合规，不卖信息本身——这是与闭源 SaaS 的道德分界，也是社区信任的来源。

09 /

风险登记册

风险等级对策
官方单引擎 MCP 升级为多源仲裁中保持中立聚合定位：官方源可作插件接入我方；自托管 + 开源是不可复制项
免费聚合方案（SearXNG 等）分流价格敏感用户高叙事锚定“可信度”而非价格；用 benchmark 数据拉开仲裁层与 SERP 列表的差距
上游搜索接口变更 / 限流政策调整中Provider 抽象 + 插件化隔离变更面；CI 版本矩阵 + 社区快速修复通道
Token 成本敏感用户流失中TTL 缓存 + 上下文预算已内建；提供单引擎降级模式；文档给出成本测算表
社区冷启动失败中双周节奏不跳票 + 48h 响应 + 五目录分发对冲单渠道风险
被贴“套壳”标签高持续公开 benchmark 与仲裁算法细节；把熔断/去重/仲裁做成可引用的技术资产
