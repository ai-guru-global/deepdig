# Surface brief — gtm/index.html (GTM 策略简报)

- Scope: 单文件策略文档（Read 模式），zh-CN，桌面优先，可打印。
- Audience/job: 团队与协作者快速掌握 DeepDig 的市场进入策略；引用章节与数据做决策。
- Action: 通读或按目录跳转；记住生态位（多源仲裁层）、90 天计划与指标护栏。
- Proof/content: 竞争格局表、四象限图、ICP 表、渠道矩阵、阶段计划、漏斗、风险登记册（全部保留既有事实内容，仅换视觉世界）。
- Constraints: 简报锁定（用户 pin）——企业级、白底、对标 IBM Carbon；单文件 HTML；无外部 JS 依赖；Google Fonts 允许。
